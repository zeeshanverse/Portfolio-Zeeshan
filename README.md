# Zeeshan Portfolio

A polished, responsive portfolio starter for Mohammed Zeeshan.

## Run locally

No build system is required.

1. Put `index.html`, `style.css`, and `script.js` in the same folder.
2. Add your `resume.pdf` to the folder.
3. Open `index.html` in a browser.

For VS Code, the Live Server extension is convenient, but it is not required.

## Before publishing

Replace these placeholders:
- Smart Attendance GitHub link
- Smart Attendance live demo if available
- MyMeal live demo link
- LinkedIn URL
- `resume.pdf`
- Any project screenshots
- Exact current CGPA if the resume is updated
